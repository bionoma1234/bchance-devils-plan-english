Square Count

Count every rectangular region whose numbers add up to the target. Squares count, too.

Round 1Correct 0 / 0Target ?
Check every possible rectangle, including those that overlap.

How to play

  1. Read the target number and the values on the board.
  2. Consider any rectangular block of one or more neighboring cells.
  3. Add the numbers within that block. Count it if the total equals the target.
  4. Overlapping rectangles count separately. Submit the total number of matching rectangles.

This is an original, solo practice recreation of the documented Count the Rectangles challenge. It is not the older blank-grid counting exercise.
